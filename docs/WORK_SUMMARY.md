# Выжимка по работе над проектом — MVP 0.1

Дата: 2026-07-03
Ветка: `claude/project-analysis-mvp-lpzdq2`

## Что это за проект

**1% Habit Tracker** — настольный трекер привычек на Go с GUI на [Fyne](https://fyne.io).
Идея: «на 1% лучше каждый день» — отмечаешь привычки выполненными и копишь серии (стрики).

## Состояние до работы

Проект был наброском из двух файлов:

- `cmd/ui/main.go` — окно, добавление привычки через диалог, кнопка «выполнено»;
- `internal/models/habit.go` — структура `Habit` без единого метода;
- пустой README, ни одного теста, данные жили только в памяти и терялись при закрытии.

## Найденные и исправленные баги

| # | Баг | В чём проявлялся | Исправление |
|---|-----|------------------|-------------|
| 1 | Капитализация ломала кириллицу | `string(text[0])` берёт первый **байт**, а русская буква занимает два: «привычка» → «Ð¿ривычка» | Работа с рунами: `unicode.ToUpper` первой руны (`capitalize()` в main.go) |
| 2 | Двойное добавление | Enter в поле добавлял привычку, но не закрывал диалог; клик «Добавить» после этого создавал дубликат | `OnSubmitted` закрывает диалог (`form.Hide()`), логика добавления вызывается один раз |
| 3 | «Выполнено» — навсегда | Кнопка блокировалась после первого клика без привязки ко дню | Отметка привязана к календарному дню; на следующий день кнопка снова активна |
| 4 | Нет сохранения | Перезапуск приложения стирал все данные | JSON-хранилище в каталоге конфигурации пользователя |
| 5 | Дубликаты привычек | `habitExists` была написана, но нигде не вызывалась | Проверка включена (`strings.EqualFold`), при дубликате — диалог «Уже есть» |

## Что добавлено в MVP 0.1

### Хранение данных (`internal/storage/`)

- Привычки сохраняются в JSON:
  - Linux: `~/.config/1prt/habits.json`
  - macOS: `~/Library/Application Support/1prt/habits.json`
  - Windows: `%AppData%\1prt\habits.json`
- Запись атомарная (временный файл + rename) — сбой при записи не теряет старые данные.
- Повреждённый файл откладывается в `.bak` и показывается ошибка, история не затирается.

### Модель (`internal/models/habit.go`)

- `MarkDone(t)` — отметка выполнения, идемпотентна в пределах дня.
- `IsDoneOn(t)` / `DoneToday()` — проверка отметки на календарный день.
- `Streak(now)` — текущая серия: сколько дней подряд привычка выполнялась.
  Семантика: серия не сгорает, пока текущий день не закончился
  (если сегодня ещё нет отметки, отсчёт идёт со вчерашнего дня);
  пропуск целого дня обнуляет серию.

### UI (`cmd/ui/main.go`)

- Загрузка привычек при старте, сохранение после каждого изменения.
- Кнопка «Отметить на сегодня» / заблокированная «Выполнено сегодня» — сброс каждый день.
- Счётчик серии «серия: N дн.» у каждой привычки.
- Удаление привычки с подтверждением (вместе с историей).
- Пустое состояние с подсказкой, скролл списка, версия в заголовке окна.

### Тесты

- `internal/models/habit_test.go` — идемпотентность отметок, границы дней, 6 сценариев стрика.
- `internal/storage/storage_test.go` — отсутствующий файл, round-trip, повреждённый файл.

Проверено: `go vet` и `go test ./...` зелёные, приложение собирается и стартует
(проверялось в виртуальном дисплее Xvfb).

## Как запустить локально

```bash
# зависимости для Linux (Debian/Ubuntu):
sudo apt install gcc libgl1-mesa-dev xorg-dev

go run ./cmd/ui        # быстрый запуск
go build -o 1prt ./cmd/ui   # или собрать бинарник
```

Подробности по Windows/macOS — в корневом `README.md`.

## Рекомендации на следующие версии (0.2+)

1. **GitHub Actions для релизных сборок** — Fyne под Windows требует C-компилятор
   (MSYS2/mingw); CI, который собирает готовые exe/бинарники на релиз, снимет эту боль.
   Главный кандидат на 0.2.
2. **ID у привычки** — сейчас имя служит идентификатором; редактирование/переименование
   потребует стабильного ID, чтобы не терять историю.
3. **Календарь отметок** — сетка прогресса за месяц (как на GitHub) для мотивации.
4. **Напоминания и трей** — systray уже тянется вместе с Fyne.
5. **Обсудить семантику стрика** — сейчас пропуск дня обнуляет серию; можно сделать
   «щадящий» режим (1 пропуск прощается) — меняется в одном месте, `Habit.Streak()`.
